二、审计方法
----------------------------------------------------------------
1. ocr delegate preview 确认工作区干净，按全仓审计处理（非 diff 审计）。
2. ocr delegate rule 拉取 6 组审查规则，覆盖 529 个代码文件；
   另含 6 个 prompts 产品文档。
3. 划分 10 个范围，全部由 general-purpose 子代理并发执行
   （受并发上限限制，实际每轮 2 个、共 5 轮完成）。
4. 主审计员对全部 medium 发现逐条读源码复核后汇总。

三、medium 级发现（19 条，已全部复核）
----------------------------------------------------------------

【安全】redact 脱敏遗漏（同一系统性缺口，两处）
1. apps/api/internal/ai/internal_tasks.go:340-348
   apps/api/internal/assistant/retrieval.go:245-254
   redact 策略下外发给模型的记录 Title 从未经过脱敏：两处均只对
   Summary/Content 调用 redactor.Redact()，而 redact 政策允许
   sensitivity != normal 的记录外发。标题中内嵌的凭据样式文本会绕过
   脱敏规则直达模型 Provider 与前端快照。

【并发正确性】
2. apps/api/internal/ai/tasks.go:423-473
   apps/api/internal/ai/internal_tasks.go:359-408
   apps/api/internal/ai/batch.go:321
   行锁顺序倒置可致死锁：cancelTask 先锁 parent 再改子任务行；
   claimTask 触发的 recoverExpiredTasks 先锁子任务（SKIP LOCKED）
   再经 updateBatchParent 锁 parent。用户取消批量任务与 worker 领取
   任务回收过期子任务并发时形成 AB-BA 环，PostgreSQL 检测后回滚
   一方，表现为偶发 500。其余 completeTask/failTask 均为子到父顺序，
   仅此路径相反。

【错误处理与可观测性】
3. apps/api/internal/assistant/indexing.go:466-470
   embedding key 解密失败被 if err == nil 静默吞掉，仍以 200 返回
   片段与空 APIKey；worker 用空凭据发起注定失败的真实外部调用，错误
   被误归因为 EMBEDDING_PROVIDER_UNAVAILABLE；主密钥配置错误时每轮
   claim 重复该循环。同文件 claimRun 有正确降级，此处缺失。
4. apps/api/internal/assistant/indexing.go:175-225（调用方 service.go
   Run 循环同样零日志）：reconciler 所有失败路径裸 return，索引卡死
   时无任何排查线索。
5. apps/ai-worker/src/task-runner.ts:908-916（assistant/index.ts 存在
   两份同构循环）：claim 阶段所有异常无条件吞掉且零日志后无限重试，
   包括 service token 失效（401/403）等永久错误——容器健康但 AI 功能
   静默失效。
6. apps/api/internal/auth/handlers_public.go:278-302
   finishChallenge 把真实数据库错误（序列化冲突、连接故障）与凭据
   错误混同，一律返回 401 并记一次限流失败，污染暴力破解计数；
   setupTOTP 与 PAT last_used_at 更新同模式。
7. apps/web/src/app/auth.ts:177-195
   logout 的 401 分支有会话归属 guard，204 成功分支没有——迟到的
   成功登出会清掉用户重新登录后的新会话。

四、low 级发现（44 条，按主题归纳）
----------------------------------------------------------------
错误契约：
- aliyun writeAliyunError 对未注册错误码 WriteHeader(0) 引发 panic
  兜底 500（internal/aliyun/http.go:99-110）。
- /internal/provider-test 把畸形输入映射为 503，导致无意义重试
  （ai-worker/src/index.ts:232-239）。
- temporary 端点 as T 断言畸形请求抛 500
  （ai-worker/src/assistant/temporary.ts:115-123）。

健壮性：
- assistant SSE 单帧坏 JSON 终止整流、无帧长上限、重连固定 600ms
  无退避（assistantSse.ts / assistantStore.ts）。
- executeDraft 工具调用 break 留下未应答 tool_calls
  （task-runner.ts:280-304）。
- auth challenge 失败记账 `_, _ =` 忽略写库错误
  （handlers_public.go:324-327）。
- embedding 响应先全量缓冲再验 32MiB 上限（model-gateway.ts:599-602）。
- backup.sh 符号链接检查晚于 mkdir 副作用（deploy/scripts/backup.sh:19-20）。

信息暴露（轻）：
- .dockerignore 未递归排除 deploy/.env*（构建上下文包含内部路径）。
- restic 测试 fixture 写入真实京东云 endpoint 与个人路径
  （test-restic-backups.sh:52）。
- ModuleNav 折叠组焦点陷阱（焦点可移出 aria-modal 对话框）。
- IME Escape 保护遗漏 2 处（SecuritySettingsView、ModuleNav 抽屉）。

死代码 / 重复 / 风格：
- json/repair.ts 与 typeGeneration.ts 死分支。
- ai-worker rewritePrompt 导出常量无消费者。
- KNOWN_PERSISTENT_EVENTS 与 KNOWN_TEMPORARY_EVENTS 集合重复。
- 嵌套三元约 10 处（jwt.ts、JsonView.vue、YamlView.vue、
  AssistantModuleNav.vue 等）。
- formatBytes 三份实现。
- 玻璃拟态 backdrop-filter 与登录页径向渐变待对照设计稿确认。

其他：
- OCR 图片重编码后上传文件名扩展名与实际字节（PNG）不一致。
- Intl.DateTimeFormat 每次调用重新构造（最多 100 条任务轮询路径）。
- 迁移副本记录在历史时间线被描述为“添加补充原始记录”。
- verify-https.sh 的 curl 未加 --noproxy，代理环境下门禁结论可能失真。
- lib.sh 用 alpine 镜像 chown，与运行镜像的 postgres uid 不一致。
